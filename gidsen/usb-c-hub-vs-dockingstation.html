USB-C hub vs dockingstation: kort besliskader

Primary: usb-c hub vs dockingstation. Marketing noemt alles “dock”. Jij wilt weten: welke poorten, welk laden, welk scherm — en stoppen met kopen.

Korte conclusie

  • Hub = mobiel / 1 scherm / weinig poorten / budget.
  • Dock = vast bureau / meer poorten / stabielere multi-monitor + PD.
  • Diepte-koopgids: dockingstation laptop zzp.
  • Pair: tweede monitor · toetsenbord · laptop.

Beslisboom (2 minuten)

  1. Alleen HDMI + 1–2 USB onderweg? → hub.
  2. Vast bureau + monitor + toetsenbord + headset-dongle elke dag? → dock overwegen.
  3. PD < wat je laptop vraagt? → ander model (batterij daalt “tijdens laden”).
  4. Dual 1440p/4K + TB-laptop? → Thunderbolt-dock onderzoeken — niet default.

FAQ

Is een USB-C hub genoeg voor ZZP-thuiswerken?

Vaak ja bij één scherm. Meer peripherals/PD → dock.

Wanneer koop ik een dockingstation i.p.v. hub?

Vast bureau, multi-device, betrouwbaar one-cable laden.

Heb ik Thunderbolt nodig?

Alleen bij laptop + use-case die bandwidth echt vraagt.
