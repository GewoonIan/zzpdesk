# ZZPDesk

Statische NL-site voor ZZP-productiviteit (affiliate SEO, €0 start).

## Lokaal

```bash
python3 -m http.server 8080 --bind 127.0.0.1
```

Open http://127.0.0.1:8080/

## Publish (gratis)

- **GitHub Pages:** repo Settings → Pages → Deploy from branch `main` / root (of `/docs` als je de site daar zet).
- **Cloudflare Pages:** nieuw project → connect repo → framework **None** → output directory `/`.

Custom domein later optioneel (~€10/jaar).
