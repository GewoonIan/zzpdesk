Dockingstation laptop ZZP: koopgids zonder kabelchaos

Één kabel erin ’s ochtends: stroom, monitor, ethernet, headset-dongle. Dat is het doel — geen 12-poorts enterprise-dock “voor later”.

Korte conclusie

  • Koop een dock als je vast bureau + externe monitor hebt en dagelijks meerdere kabels wisselt.
  • Koop een hub als je vooral onderweg bent of maar 1 HDMI + SD/USB nodig hebt.
  • Check eerst: laptop USB-C/Thunderbolt + PD-wattage + hoeveel schermen.
  • Pair met laptop-gids en tweede monitor.

ZZP-default: start met wat je wekelijks aansluit. Geen Thunderbolt-dock “omdat het kan” als je één 1080p-scherm hebt. Kort besliskader: USB-C hub vs dockingstation. Typen: beste toetsenbord thuiswerken.

Harde checks vóór je koopt

  1. Poort op de laptop: USB-C data? USB-C met DP Alt Mode? Thunderbolt 3/4?
  2. Laden: welke wattage heeft je originele lader? Dock/hub PD ≥ die behoefte (vaak 65–100W).
  3. Schermen: 1 of 2? Welke resolutie (1080p / 1440p / 4K)?
  4. Kabelstandaard: HDMI, DisplayPort, of USB-C naar monitor?
  5. Ethernet: nodig voor stabiele calls? Anders skip.

Poorten die ZZP’ers écht gebruiken

  • HDMI of DP → monitor (monitor-gids)
  • USB-A → muis/toetsenbord/receiver
  • USB-C passthrough / PD → laptop laden
  • 3.5 mm of USB → headset
  • Ethernet — optioneel, fijn bij matige wifi

SD-kaartreader: alleen als je foto/video doet. Anders marketing-feature.

Koopklassen (zonder merkhype)

A — Compacte hub (onderweg + 1 scherm)

HDMI + 2× USB-A + PD. Past in de laptophoes. Amazon/Bol: filter op jouw poort + reviews op “laadt wél / laadt niet”.

B — Bureau-dock (vast + 1–2 schermen)

Meer USB, ethernet, betere multi-monitor. Let op laptop-compatibiliteitslijst van de fabrikant.

C — Thunderbolt-dock

Alleen als je laptop TB heeft én je dual high-res monitors + bandwidth nodig hebt. Duurder — niet default.

Setup die werkt

  1. Dock/hub vast op bureau; monitor + randapparatuur erin.
  2. Eén USB-C-kabel naar laptop (data + power als PD klopt).
  3. Test: scherm, laden (batterij % stijgt), headset, muis.
  4. Label de kabel — future-you dankt je.

FAQ

Heb ik als ZZP’er een dockingstation nodig?

Alleen bij vast bureau + meerdere peripherals. Anders volstaat een hub.

USB-C hub of echt dockingstation?

Hub voor licht/mobiel; dock voor bureau + meer poorten/power.

Welke power delivery heb ik nodig?

Minimaal wat je laptop vraagt (check laderwattage). Te weinig PD = lege batterij tijdens “laden”.
